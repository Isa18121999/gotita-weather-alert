# GÓTITA — tu alerta antes de la lluvia

Plataforma de alerta temprana del fenómeno de El Niño y precipitaciones en Perú.

Este repositorio integra el prototipo de **Propuesta 1** y la base del proyecto Pluvix/Gótita: dashboard, mapa, alertas, noticias y preparación para una arquitectura cloud.

## Desarrollo local

```bash
npm install
npm run dev
```

Consulta la documentación de `backend/README.md` y `infra/README.md` para la API y la arquitectura cloud.

> Nota: los datos de Open-Meteo se utilizan como fuente meteorológica de prototipo y no deben presentarse como mediciones oficiales de SENAMHI.
